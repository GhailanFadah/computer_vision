## Overview

Three-program system for camera calibration, AR object rendering, and Harris corner feature exploration. A chessboard target is used to calibrate the camera and establish a coordinate frame for projecting virtual 3D objects into a live video stream.

---

## Environment

- **OS:** Linux / macOS
- **Language:** C++17
- **Libraries:** OpenCV 4.x
- **Build:** GNU Make

## Programs

### 1. calibrate

Collects chessboard frames interactively and computes camera intrinsics.

```bash
./calibrate
```

| Key | Action |
|-----|--------|
| `s` | Save current frame as a calibration sample |
| `c` | Run calibration (requires >= 5 saved frames) |
| `q` | Quit |

Prints the camera matrix and distortion coefficients before and after calibration, along with the final re-projection error. Saves results to `camera_matrix.csv` and `distortion.csv`.

A re-projection error under 0.5 px is a good result. Collect frames at varied angles and distances for best accuracy.

---

### 2. ar_render

Loads calibration data and overlays virtual 3D objects onto a live video stream using the detected chessboard pose.

```bash
./ar_render
```

Requires `camera_matrix.csv` and `distortion.csv` to be present (run `calibrate` first).

| Key | Action |
|-----|--------|
| `1` | Toggle 3D axes |
| `2` | Toggle wireframe cube |
| `3` | Toggle wireframe pyramid |
| `4` | Toggle spacecraft |
| `p` | Toggle real-time rotation/translation printing |
| `q` | Quit |

The spacecraft is a multi-part model (fuselage, cockpit, swept wings, engine nacelles, tail fin) rendered with translucent filled faces and a wireframe overlay, floating above the board center.

Translation values are in units of one chessboard square. Set `SQUARE_SIZE` in `calibUtils.h` to your actual square size in millimeters for metric output.

---

### 3. harris

Live Harris corner detector with real-time parameter controls via trackbars.

```bash
./harris
```

| Key | Action |
|-----|--------|
| `v` | Cycle view mode (overlay / heatmap / side-by-side) |
| `q` | Quit |

| Trackbar | Effect |
|----------|--------|
| `blockSize` | Neighborhood size for corner detection (2–10) |
| `aperture` | Sobel kernel size: 0→3, 1→5, 2→7 |
| `k x100` | Harris sensitivity constant (typical range: 0.04–0.10) |
| `threshold` | Minimum response strength to display a corner |

Works best on high-contrast patterns — a printed chessboard, text, or geometric shapes. Corners are color-coded green (weak) to red (strong) by response magnitude.

---

## Calibration Target

6×9 inner-corner chessboard (i.e. a 7×10 square board). The board must be fully visible and unoccluded for detection to succeed. Print on matte paper to avoid specular reflections.

---

## Notes

- `calibUtils.h` defines `BOARD_COLS`, `BOARD_ROWS`, and `SQUARE_SIZE` — update these if using a different board
- The AR programs use negative Z for "up" since OpenCV's board frame has Z pointing into the board surface
- Face draw order in the spacecraft model is back-to-front; no depth buffer is used
